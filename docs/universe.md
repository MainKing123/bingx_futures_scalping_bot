# Пять пар для торговли

Динамический список содержит ровно пять USDT-фьючерсов. Сначала берётся [рейтинг капитализации CoinGecko](https://docs.coingecko.com/demo/reference/coins-markets), затем остаются монеты с `market_cap_rank <= 20`, кроме стейблкоинов, обёрнутых и стейкинговых производных. Из них выбираются доступные для API MEXC линейные бессрочные USDT-контракты с дневным оборотом минимум 50 млн USD (`amount24`, нормализованный как `quoteVolume`).

Волатильность — среднее `true_range / close * 100` за последние 96 закрытых 15-минутных свечей. Для первого `true_range` используется закрытие дополнительной предыдущей свечи. Это средняя нормализованная амплитуда за 24 часа; доходность за сутки не используется вместо волатильности.

Текущие `RuntimeSettings` обязательно включают проверенные BTC/ETH и добавляют три остальных кандидата с наибольшей волатильностью. Core не обходят фильтры капитализации, ликвидности и пригодности контракта: недоступный BTC/ETH приостанавливает отбор. Сохранённый cache содержит политику core и не переиспользуется после её изменения. Замороженная V1 с базовыми `Settings` выбирала пять наибольших значений без обязательного ядра; её прежний снимок и результаты сохраняются отдельно.

Результат, все прошедшие фильтры кандидаты, капитализация и время источников сохраняются в `.cache/universe.json`. Полный список используется без сетевых запросов только внутри `UNIVERSE_REFRESH_SECONDS`; стандартно обновляется каждый час. При недоступном API капитализации можно повторно использовать проверенный снимок капитализации не старше шести часов, заново получив MEXC-оборот и свечи. Просроченный итоговый список, неполные свечи и недостаточное число кандидатов останавливают выбор. Автоматической замены малоизвестными монетами нет.

`PAIR_SELECTION=fixed` — явное переопределение для ровно пяти настроенных пар; оно не утверждает, что эти монеты входят в топ по капитализации. В динамическом режиме `TRADING_SYMBOLS` не служит запасным списком.

Для исторического теста сегодняшнего списка нужно явно указывать, что применяется текущий состав к прошлому периоду. Это не исторический рейтинг капитализации и не доказательство отсутствия смещения выбора.
