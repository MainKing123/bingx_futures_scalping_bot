# Причинная source-проверка первых V4-идей

Искались первые 3 уникальные accepted-идеи default V4 по хронологии на MEXC BTC/ETH train. При одинаковом закрытии BTC рассматривается раньше ETH; исходы не ранжируются. Пороги фиксированы: ATR 0.8, body-range 0.6, body-opposite 1, max-wait 3 от первого raid; одна структура post_sweep_break. Времена train: 2025-11-08T15:25Z → 2026-02-06T15:20Z.

Найдено 0 уникальных кейсов после 7560 рассмотренных закрытий разрешённых сессий, до 2026-02-06T14:55:00+00:00. Повторных accepted-диагнозов уже выбранного ID: 0.

Сигналы получали только закрытые префиксы H1≤2030, D1/M5≤110 (контекст D1≤80). Проверены хеши 6 CSV. Полные архивы прочитаны для хеша; диагностические значения позже разрешённого train-end исключены. Ни одному сигналу не передан бар, закрывающийся после него. Replay, ордера, комиссии, funding, PnL и будущие исходы не рассчитывались. Итоговый holdout не открывался. Код двигателя и замороженный source_review проверены хешами до/после и не изменены.

Три уникальные accepted-идеи за разрешённое окно не найдены. Это отсутствие нужного количества source-кейсов, а не оценка прибыли или основание менять пороги.

## Причины отказов на рассмотренном префиксе

Единица — первое непройденное условие одного закрытия, не уникальный торговый замысел; тот же контекст может повторяться многократно. Просмотр должен был остановиться при 3 найденных идеях либо в конце train; достигнут конец train.

## Граница соответствия

Эта проверка искала кейсы объявленной численной цепочки A/C/B→H1→M5→2R. Она не устанавливает совпадение ручных глобальных трендов/масштабов автора, качество каждой V или его заявленные 70%. Немедленная C и исключение pre-A/right-A являются гипотезой V4; контртрендовый отскок может формально пройти. Известная авторская дата уже раскрыта в отдельном source-документе и не используется для оценки исходов здесь. Поскольку accepted-кейсов нет, 20 проверок полной цепочки и просмотр их графиков выполнить не удалось.

В outputs/strategy_v4_case_reviews.json сохранены параметры, границы причинного окна, хеши источников, пустой список кейсов и причины отказов. Параметры, freeze, планы и число profitability trials после этого source-проверочного просмотра не изменялись.
