# Отдельная проверка BTC/ETH на Binance

Данные этого эксперимента относятся к **Binance USD-M perpetual futures**, а не к MEXC. Цены, минутные свечи и funding одной биржи не смешиваются с другой. Положительный результат здесь будет свидетельством исторической работы правил на этом рынке; он не подтверждает цены исполнения, ликвидность или прибыльность того же бота на MEXC.

Источник — [официальный публичный архив Binance](https://github.com/binance/binance-public-data). Модуль `python -m app.external_data` сохраняет `.cache/binance_core/snapshot.json`, проверяет каждый ZIP по опубликованному `.CHECKSUM` и фиксирует URL, SHA256, размер и момент загрузки. Архивы биржа может исправлять, поэтому повторное исследование использует зафиксированные файлы и их хеши.

Набор заранее ограничен BTCUSDT и ETHUSDT. Минуты и funding: 2024-01-01 00:00 UTC — 2026-01-01 00:00 UTC, исключая правую границу. На каждый инструмент получено **1 052 640 фактических минутных свечей без пропусков** и **2 193 фактических расчёта funding**. D1 за 2022–2023 служит только прогревом контекста. M5/H1/H4/D1 в интервале минутной истории строятся из полных групп наблюдаемых минут; отсутствующие минуты не восстанавливаются. Объём выражен в базовом активе.

Время открытия свечей хранится в UTC с точностью источника. Funding сохраняет точные `calc_time`, включая небольшую задержку в миллисекундах; такая задержка не округляется при расчёте денег. Проверка покрытия допускает только задержку менее минуты относительно ожидаемой восьмичасовой границы. Для цены funding используется последнее известное закрытие той же биржи как прокси mark price; неоднозначные выгодные начисления обрабатывает консервативная модель replay.

Предложенное хронологическое разделение до просмотра доходности: train — 2024 год; validation — январь–июнь 2025; final test — июль–декабрь 2025. Фактический неизменяемый план и код выбора кандидата сохраняет `app.research_suite`; этот файл сам по себе не утверждает, что этапы были выполнены или что есть прибыльный кандидат. Перебор параметров, число попыток, комиссии и результаты остаются отдельными от опубликованного исследования MEXC v1.

Только публичные GET-запросы к архиву, ключи API не нужны. Этот модуль не отправляет торговые заявки.
